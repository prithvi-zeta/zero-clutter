## Added

- Every screen gets 4 questions: can it go, can it be better, is it confusing, how will users read it.
- Flows are checked screen to screen, the way a user goes through them.
- 6 new rules:
  - Copy has proper punctuation.
  - One theme and one art style across the app.
  - Choices sit in their own labelled card.
  - Every wait for the server is designed.
  - Buttons say what happens next.
  - A flow keeps its story from start to end.
- New example: the receive money flow.

## Updated

- Linked docs and comments in the design file now count as the spec.
- Better wording goes back to the approver as a question, not a silent change.
- Spacing is checked by eye, not just by measuring.
- Text shows from the first frame. Only one thing moves.
